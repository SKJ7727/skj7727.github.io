Privacy Policy: GTA6 Shorts Pipeline

Last updated: 24 November 2026

Who uses this app

GTA6 Shorts Pipeline is a private tool used only by its owner, for the owner's own YouTube channels. Nobody else signs in to it.

What Google data it accesses

  • YouTube (only the owner's own channels): uploads and schedules the owner's videos and reads the status of those uploads.
  • Google Sheets: only the spreadsheet files this app created itself (Google's "drive.file" access). Other files are never seen.

How the data is used and stored

  • Data is used only to prepare, upload and schedule the owner's own videos.
  • Sign-in tokens and working files are stored only on the owner's own computer.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • There is no server, no analytics and no cookies on these pages.

YouTube and Google

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Access can be removed at any time at myaccount.google.com/permissions.
